# 🗂️ projeto-portfolio

✅ **Projeto concluído.**

Página de portfólio desenvolvida como **projeto de conclusão do curso de HTML e CSS do [Curso em Vídeo](https://www.cursoemvideo.com/)**, ministrado por Gustavo Guanabara. O portfólio apresenta uma ficha profissional, skills, formação acadêmica e uma vitrine de projetos, reunindo boa parte do que foi aprendido ao longo do curso em uma única página.

🔗 **[Ver página online](https://renanbrandaodev.github.io/projeto-portfolio/)**

## ✨ Funcionalidades

- **Navegação por âncoras** com rolagem suave entre as seções (ficha, skills, formação e projetos)
- **Alternância de tema claro/escuro**, com a preferência salva no `localStorage`
- **Barras de progresso** para exibir o nível de cada habilidade
- **Cards de projetos expansíveis** (`<details>`/`<summary>`), mostrando um resumo e permitindo expandir para ler mais
- **Ícones do Font Awesome** para navegação, redes sociais e skills
- Layout **responsivo**

## 🏗️ Estrutura das seções

| Seção | Conteúdo |
|-------|----------|
| Ficha | Foto, apresentação e links para redes sociais |
| Skills | Nível de domínio em HTML5, CSS3, JavaScript, PHP e soft skills |
| Formação | Linha do tempo com histórico acadêmico |
| Projetos | Vitrine com os principais projetos construídos durante o curso |

## 📌 Sobre

Este projeto marca a conclusão do curso de HTML e CSS, reunindo em uma única página prática os principais conceitos estudados: estrutura semântica, estilização, responsividade e interatividade com JavaScript.
